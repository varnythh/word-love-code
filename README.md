# Word Love Code 💌

**Word Love Code** adalah sebuah web app sederhana yang memvisualisasikan kata-kata cinta dan perasaan lewat animasi HTML dan JavaScript.  
Proyek ini dibuat tanpa alasan yang jelas, hanya dorongan perasaan terhadap seseorang... yang bahkan aku sendiri tak benar-benar tahu.

## ✨ Fitur
- Visualisasi kata-kata dengan efek animasi
- Tampilan minimalis dan penuh nuansa
- Dirancang untuk menyampaikan rasa melalui kode

## 🛠️ Teknologi yang Digunakan
- HTML
- JavaScript (Vanilla)
